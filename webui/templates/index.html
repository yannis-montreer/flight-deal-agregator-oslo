Ajouter une clé SerpApi
  1. Sur la NUC, ouvre C:\Users\salon\flight-deal-agregator-oslo\.env avec le Bloc-notes.
  2. Ajoute une ligne SERPAPI_KEY_3=ta_clé (le nom doit contenir SERPAPI_KEY), enregistre.
  3. Dans PowerShell, dans ce dossier : docker compose up -d (relit .env, ne déclenche aucun run).
  4. Recharge cette page : la clé apparaît ici et dans le choix de clé des alertes.

La valeur de la clé ne passe jamais par cette interface.
